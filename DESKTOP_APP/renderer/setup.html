Welcome to JMS Local Server

This wizard will set up the JMS factory server on this computer in a few steps. The server connects your factory floor to the main JMS site automatically.

Before you start, make sure:
• Node.js LTS is installed on this computer
• PostgreSQL 14+ is installed and running
• You have your Factory ID and Node Key (from the main site → Local Servers)
🏭
What this does
Runs a background server that syncs factory data with the main JMS site every 15 seconds. It starts automatically when Windows starts.
