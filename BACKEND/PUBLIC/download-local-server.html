JMS Local Server

Desktop software for factory computers. Connects your factory floor to the main JMS site and syncs data automatically.

📋 Installation Steps

  1. Click Download and run the installer
  2. Follow the setup wizard (takes ~2 minutes)
  3. Enter your Factory ID and Node Key
    (Get these from the main site → Settings → Local Servers)
  4. Click Install & Start — done!
  5. Run REGISTER_AUTOSTART.bat (in install folder) as Administrator so it starts on reboot
